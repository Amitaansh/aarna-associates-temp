# Extracted product cutouts (from your brochures)

Transparent PNGs lifted straight from the brochure PDFs. These are the
manufacturers' own product renders — clean, no background.

## How to put one on a card
Rename the file to the product's slug and move it into the brand folder:

    photos/_library/vardhmaan/p12_03.png   ->   photos/magppie/aristo.png

The slug = product name, lowercase, punctuation to hyphens
(e.g. "Aristo" -> aristo, "Super Turbo HD" -> super-turbo-hd).
Full list of expected filenames is in photos/manifest.csv.
Cards with no file fall back to the line icon automatically.

## What's here
- _library/kenstar-airfryer  (44) — clean, high-res. Best source.
- _library/vardhmaan         (43) — clean cookware cutouts.
- _library/kenstar-washing   (12) — Power Wash / Maxima machines.
- _library/maharaja          (2)  — the Maharaja appliances PDF is a
  low-res, image-only file, so almost nothing usable came out of it.
  Better to pull those from maharajawhiteline.com product pages.

Filenames carry the source page: p12_03 = page 12 of that brochure,
3rd image. Open the brochure to the same page to see which product it is.
